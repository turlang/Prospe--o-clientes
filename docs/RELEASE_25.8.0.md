# LeadHunter Pro 25.8.0

## Objetivo

Transformar a visualização “Níveis de prospecção” em um funil comercial profissional, responsivo e semanticamente correto.

## Implementação

- seis etapas de avanço formam o funil principal;
- recusados aparecem como saída do fluxo, sem serem tratados como avanço;
- números e percentuais permanecem vinculados ao relatório comercial;
- leitura executiva mostra avanço, negociação, fechamento e concentração;
- CSS usa `clip-path`, sem biblioteca externa de gráficos.

## Responsividade

O funil mantém a forma no desktop e usa larguras mínimas legíveis no celular. A leitura executiva passa para uma coluna em viewports estreitas.
