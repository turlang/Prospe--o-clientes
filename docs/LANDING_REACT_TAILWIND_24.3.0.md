# Landing React + Tailwind 24.3.0

A versão 24.3.0 refaz a composição visual da landing comercial do LeadHunter Pro.

## Ajustes principais

- Hero escuro em duas colunas com título equilibrado e destaque controlado.
- Tipografia mobile reduzida com `clamp`, evitando blocos de texto excessivos.
- Dashboard demonstrativo com leads, score, potencial financeiro e abordagem com IA.
- Barra visual com as quatro etapas da prospecção.
- Seção de ferramentas em formato bento e CRM Kanban demonstrativo.
- Cards de público, planos e CTA final reorganizados para conversão.
- Header compacto e responsivo, com estados de hover e foco.
- Proteção contra overflow horizontal e quebra de palavras em telas estreitas.
