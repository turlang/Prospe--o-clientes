# Release 25.4.0 — Diagramação consistente

A release corrige proporções, espaços vazios, escala tipográfica e alinhamento das cinco telas da landing sem scroll.

## Contratos preservados

- documento em `100dvh` sem scroll de página;
- navegação por botões e hash;
- planos sincronizados pelo Admin;
- fallback estático equivalente ao React;
- responsividade mobile-first.
