FAQ

Perguntas rápidas

O sistema envia WhatsApp automaticamente?

Não. Ele gera mensagens e organiza follow-ups, mas o envio deve ser revisado pelo usuário.

Preciso de MongoDB para testar?

Não. O projeto funciona localmente com JSON. Para produção, use MongoDB Atlas.

O pagamento já está integrado?

A estrutura está pronta e o checkout Mercado Pago é opcional quando o token é configurado.

Pronto para transformar prospecção em rotina?
